## Design Context

### Users
Dev team using a shared monitor/projector during morning standups. The interface is *performing* — everyone in the room is watching it. This creates an opportunity for theatrical, crowd-pleasing moments. Animations should feel like a game show, not a productivity tool.

### Brand Personality
Playful, chaotic, irreverent. The app has opinions. It roasts long speakers, spawns emojis when someone goes overtime, shakes the screen. It should feel like the team's own private inside joke rendered as software.

Anti-reference: JIRA / Salesforce — corporate density, gray utility-first aesthetic, zero personality.

### Aesthetic Direction
Dark mode (projector/office context). Warm amber/coral palette (already established). Fonts: Bricolage Grotesque (display) + Figtree (body). No glassmorphism, no generic shadows. High-contrast, punchy, stage-light energy. Feels theatrical, not generated.

### Design Principles
1. **Theatrical over functional** — this app is projected on a wall; it should have presence and performance energy
2. **Chaotic delight** — the randomness and irreverence are features, not bugs; lean in
3. **Team as cast** — people are characters in a show, not items in a queue
4. **Motion serves drama** — transitions should build anticipation, not just move things
5. **No boring moments** — every state change is an opportunity for a reaction
6. **Morning-ready** — despite the chaos, the current speaker should always be immediately clear
